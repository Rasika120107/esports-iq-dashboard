# Esports IQ — Student Extension Pack (Remaining 20%)

## Suggested student tasks
1. **Sales trends:** date-range filter, monthly revenue chart, period-over-period changes.
2. **Demand forecasting:** establish a moving-average baseline, test against held-out data, report MAE/MAPE limitations.
3. **Product recommendations:** explainable complementary-item suggestions; use transaction data before claiming co-purchase patterns.
4. **Supplier scorecards:** lead time, unit cost, returns/defects and on-time delivery with documented scoring.
5. **Database and access:** SQLite/PostgreSQL persistence, authentication, role-based permissions, shop-level data isolation and audit logs.
6. **Testing and deployment:** validation tests, empty states, duplicate handling, deployment instructions and privacy review.

## Definition of done
- Works with both sample and uploaded data.
- Includes input validation and sensible empty states.
- Documents calculations and assumptions.
- Adds automated tests for new calculations.
- Includes screenshots and a short contribution note.

Students should choose enhancements and implement them; these are not included in the current starter app.
